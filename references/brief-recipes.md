# Brief recipes

Four copy-paste briefs that already encode the phases. Fill the brackets, delete
what does not apply, and keep the order — the order is the workflow.

Shared shape of every brief:

```
audience:     [who specifically]
promise:      [the one thing they should believe after]
action:       [the single thing they should do]
proof:        [what is actually true and shown]
aspect + length: [16:9 1080p, 60–75 s]
tone:         [one word]
muted-safe:   [what must be readable with no sound]
```

## Product film (device direction)

```
Make a [length] app promo for [product], audience: [who].
Direction: #device. The hero is the real UI, reproduced exactly — same screens,
same strings, same tokens; no invented screens.
Beats: hook claim (3 s) → device enters (2 s) → [feature 1] (6 s) →
[feature 2] (6 s) → [feature 3] (6 s) → proof grid (5 s) → end card (5 s).
Every feature beat: one screen, one caption of ≤ 6 words, VO line ≤ 14 words.
End card: icon + wordmark + one action ([handle / URL]) + [contacts].
Deliver 16:9 and 9:16 (re-composed, not cropped) + thumbnail + cover.
```

## Launch trailer (30 s)

```
Make a 28–32 s launch trailer for [thing], audience: [who], emotion: hype.
Direction: #launch. Score 120 BPM, cuts on the kick.
Structure: 8 beats; the product appears at 0:06 and never leaves; drop at 0:18;
final card holds 3 s.
Copy: ≤ 3 words per beat, one claim total, no feature list.
End card: [action], said in [n] words.
```

## UI walkthrough (screen-recorded feel)

```
Make a [length] walkthrough of [flow] in [product].
Direction: #ui-film. Follow one user action end to end — [action] — with the cursor
never shown; the UI responds on its own.
Camera: crop in on the area that changes; max 1 camera move per beat.
Captions: name the step in ≤ 4 words, bottom-right of the crop, never over UI.
```

## Arabic editorial / trust film

```
Make a [length] Arabic (MSA, fully vocalised) film about [subject].
Direction: #editorial. Paper ground, ink, one accent; Naskh or humanist sans Arabic.
VO: [n] lines, 8–14 words each, tashkeel complete, brand name in Latin.
Beats: title → claim → 2 evidence beats → stamp → action.
Readable at 1:1; no letter-spacing; words revealed as units.
```

## Reel / short (9:16 only)

```
Make a [18–25] s vertical for [product], audience: [who].
Direction: [device | kinetic]. Safe areas: 220 px top, 320 px bottom untouched.
Copy: 2 lines max, 68–120 px type; the hook must land in 1.2 s.
Structure: hook → 2 proof beats → action. One idea total.
```
